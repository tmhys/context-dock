保存と反映

    1. 「GitHub に保存」すると、1分ほどで Actions が Tasker の XML と KWGT のプリセットを作り直す
    2. Tasker で ContextDock 更新 を実行 → Tasker/ と Kustom/widgets/ に最新が入る
    3. Tasker：古い ContextDock プロジェクトを削除 → 家アイコン長押し → Import Project
    4. KWGT：アプリやモードを変えたときだけ、ウィジェットをタップして Context Dock を選び直す
